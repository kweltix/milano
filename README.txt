MILANO — сайт (готовый фронтенд)
Файлы: index.html, style.css, script.js, assets/ (фото банок и логотип халяль).
Запуск: откройте index.html в браузере или загрузите папку на любой статический хостинг.
Админ-панель: адрес /index.html#/admin, вход admin@milano.ru / admin123 (СМЕНИТЕ: хэш в script.js, переменная users.hash — SHA-256).
Тема (тёмная по умолчанию) и язык (RU по умолчанию) переключаются кнопками в шапке.
ВАЖНО: данные (вкусы, статьи, точки, заявки, пользователи) сейчас хранятся в localStorage браузера.
Для боевого запуска нужен сервер/БД (схема — bd.txt): вынесите функции save()/D в API.
